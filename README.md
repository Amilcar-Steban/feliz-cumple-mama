# Feliz cumpleaños, Mamá 🎁

Tarjeta de regalo animada con el enlace de descarga de la app **Ruby Castillo**.

- `index.html`: la tarjeta. Es una página sin dependencias: solo usa las fuentes de Google Fonts.
- El APK se publica como archivo del Release `v1.1.8`, porque GitHub no admite archivos de más de 100 MB dentro del repositorio. El botón apunta a `releases/latest/download/RubyCastillo.apk`.

Para actualizar la app, crea un Release nuevo con el archivo `RubyCastillo.apk` y el botón descargará esa versión.
